这张票同时建立归因纯函数——把「三层各自处于什么状态」从诊断报告里算出来，渲染只读它的结果，不再回头读原始报告里的状态字段。这是本次改造唯一的新增抽象，必须与渲染一起落地，否则就是横向切片。

归因规则（来自规格，全部要覆盖）：

1. `env` 层：诊断报告里是命中 → 命中，取该层的值；是「不可观测」→ 不可观测，值渲染为 `?`。
2. `patch` 层：值存在但不在档位取值域（`off / lite / full / ultra`）里 → 非法，**不看诊断报告报的命中**。这是对既有判据缺陷的渲染层防御：现状会把非法值报成命中，照抄就会显示一个不存在的档位「生效了」。合法且等于生效值 → 命中；合法但不等 → 写了没赢。
3. `fallback` 层：前两层都没命中时 → 命中，值取内置默认值；否则 → 没轮到。
4. 非法不阻断扫描：非法值被忽略，继续往下一层走，因此 `不可观测 + 非法 + 命中` 是合法组合。
5. 没轮到的层一律不再区分有值没值，整体淡出。
6. 生效值来自哪一层只用于无障碍描述，卡面不出现「来自 XX」这类文字——管道本身已经表达。
