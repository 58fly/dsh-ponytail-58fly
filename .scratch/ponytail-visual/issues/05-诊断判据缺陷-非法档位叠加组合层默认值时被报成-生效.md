# 05: 诊断判据缺陷：非法档位叠加组合层默认值时被报成「生效」

**What to build:** 登记并修复诊断判据缺陷：用户写了非法档位、而组合层有合法默认值时，诊断报告会把非法值报成「生效」。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 新增回归测试：`user='bogus'` + `base='full'` → 该层 `invalid`、生效值为 `full`、非法值不被任何层报成 `hit`
- [x] 新增回归测试：`user='bogus'` 且无 `base` → 仍为 `invalid`（原行为不退化）
- [x] 新增回归测试：`user` 与 `base` 都合法且 `user` 优先 → 该层 `hit=user`，值同源
- [x] 修复后 `patchMode` 与 `patchRaw` 取自同一层，代码里不再出现跨层 `??`
- [x] 现有 `scripts/verify.mjs` 诊断哨兵全部通过，无一条需要放宽
- [x] `pnpm typecheck && pnpm build && pnpm test && pnpm verify` 通过

**现象**（已用真 `diagnose()` 实测）：

```
输入：value={defaultMode:'full'}, base={defaultMode:'full'}, user={defaultMode:'bogus'}
输出：env:unknown  patch:hit=bogus  fallback:shadowed  overriddenBy=null
```

面板于是宣称一个不存在的档位 `bogus` 正在生效，而实际运行时用的是 `full`。同一份输入的另一种组合（`user='bogus'` 且无 `base`）能正确报 `patch:invalid`，说明问题只在「user 与 base 同时存在」这条路径上。

**根因**：`src/l0/diagnosis.ts:157-160`

```ts
const patchMode = user.mode ?? base.mode;
const patchRaw = user.raw ?? base.raw;
```

`patchMode` 与 `patchRaw` 各自独立地做 `??`，取到的是**不同层**的值：`patchRaw` 来自用户的 `bogus`，`patchMode` 落到 base 的 `full`。后续用 `patchMode === effective` 判命中，于是命中，而展示用的 `patchRaw` 是那个非法值。

**修复方向**：`patchMode` 与 `patchRaw` 必须同源——既然 `patchRaw` 优先取用户层，`patchMode` 也必须优先取用户层的解析结果（含「解析失败」这个结果），不许跨层兜底。用户层写了非法值时该层应判 `invalid`，扫描继续往 fallback 走。

**为什么单独一张票**：本次 UI 改造（规格 00 及其子票 01–04）明确不碰诊断契约，渲染层用归因纯函数绕开了这个缺陷，但缺陷本体仍在，且已被下一张 UI 票引用为「遗留风险」。

## 收口

**根因**：`src/l0/diagnosis.ts` 里 `patchRaw = user.raw ?? base.raw` 与 `patchMode = user.mode ?? base.mode` 各自独立做 `??`，第二次 `??` 在用户层「写了但不合法」时会跨到组合层，于是 raw 是用户的垃圾值、mode 是组合层的合法值，`patchMode === effective` 成立 → 报 `hit`。

**修复**：按 `present` 一次判定归属，`patchFromUser` 为真就整段取用户层（含解析失败），不再各字段独立兜底。`overriddenBy` 也改用同源的 `patchRaw`，删掉派生字符串 `patchOrigin`，注脚直接看布尔真值。

**实测（编译产物 lib/l0/diagnosis.js）**

| 输入 | 修复前 | 修复后 |
|---|---|---|
| value=full, base=full, user=bogus | patch `hit(bogus)`，effective=full | patch `invalid(bogus)`，fallback `hit`，effective=full |
| value=full, user=bogus（无 base） | patch `invalid(bogus)` | 不变 |
| value=ultra, base=lite, user=ultra | patch `hit(ultra)` | 不变（值同源） |
| value=lite, base=lite | patch `hit(lite)` + 组合层注脚 | 不变 |
