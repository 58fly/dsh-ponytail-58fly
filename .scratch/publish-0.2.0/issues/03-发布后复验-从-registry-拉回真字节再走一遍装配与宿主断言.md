# 03: 发布后复验：从 registry 拉回真字节再走一遍装配与宿主断言

**What to build:** 一条发布后能手动跑的复验命令：它从 registry 上把那个版本的真实压缩包拉回来，核对字节与 registry 记录的摘要一致，再拿这份字节跑一遍装配四段与宿主发现断言。版本还没发出去的时候，它给一句「这个版本还没发布」并退非零，而不是把 registry 的 404 栈甩到人脸上。

**Blocked by:** 01（宿主发现断言要先长在装配验证里, 复验才有东西可复用）

**Status:** ready-for-agent

- [ ] 新增一条包脚本，独立于发布前钩子（发布前包里还没有那个版本，钩子里跑它必然假红）。
- [ ] 输入必须来自 registry（带版本的打包命令会走网络），不读仓根那份本地压缩包，也不落依赖目录。
- [ ] 完整性核对两侧都用包管理器自己算的摘要，不自己拼哈希算法；不一致时给明确文案并退非零。
- [ ] 版本不存在时输出「这个版本还没发布」并退非零，不打印 registry 404 的栈。
- [ ] 复用装配验证既有的压缩包输入参数，不新增参数面。
- [ ] 拉到真包时走完装配四段断言与宿主发现五项断言。
- [ ] 离线可测的那条路径（不存在版本）有断言覆盖：给出结论且退出码非零。
- [ ] 不改变装配验证三种形态的既有行为；其自检仍全绿。
