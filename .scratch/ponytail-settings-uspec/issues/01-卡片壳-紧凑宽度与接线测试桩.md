# 01: 卡片壳、紧凑宽度与接线测试桩

**What to build:** 

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 页面大标题逐字为 `Ponytail`，不带 `58fly`；标题下一句定位说明讲清「这是给开发者看的调试面板」，不是产品介绍语。
- [ ] 三个区域各是一张卡片，视觉参数一致：二级底色、0.5px 三级边框、中等圆角、12px 内边距；卡头左侧小标题、右侧最多一个动作位。
- [ ] 颜色、等宽字体、圆角全部取宿主主题变量；面板文件内不出现任何写死色值（`pnpm run verify` 的诚实卡口继续零命中）。
- [ ] 面板宽度降到 480px 以下时三张卡切紧凑布局，不出现横向滚动条；限制来源是面板自身宽度而非视口宽度。
- [ ] 卡片壳与宽度模式是**共享件**，后续三张卡直接复用，不在各自卡片里重复实现。
- [ ] 现有接线测试继续通过：面板在桩环境下可被调用；桩里补齐新用到的官方原语与浏览器测宽能力（当前桩只有按钮、分段控件、标签三个原语，且没有任何测宽接口），补齐后断言仍然只校验注册面与写回调，不新增 DOM 断言。
- [ ] `pnpm run typecheck`、`pnpm test`、`pnpm run verify` 全绿；客户端构建产物能生成且体积无异常增长。
- [ ] 不引入新依赖，不引入 jsdom 或任何测试渲染器。

## 父票

规格 00「Ponytail 设置页 UI 重构：三卡片、五态图例、指标表格与悬停帮助」（`.scratch/ponytail-settings-uspec/`）。

## 要做出什么

打开设置页的 Ponytail 段，看到的是**三层独立的卡片**而不是一段带小标题的长文本：页面标题只写 `Ponytail`，下面一句定位说明，再往下依次是档位、诊断链、效率统计三张卡。每张卡的头部结构一致（左侧小标题、右侧最多一个动作位），卡片底色、边框、圆角、内边距三张卡完全一样。

把面板拉窄到 480px 以下，三张卡一起切进紧凑布局（重排而不是横向滚动）；松开恢复。这个宽度判定测的是**面板自己的宽度**，不是窗口宽度——设置页被塞进侧栏和分屏时，窗口宽不代表面板宽。

这一步只把壳立起来：三张卡的内容仍是现有渲染，暂不重排。完成后整页视觉上已经是「三个边界清楚的功能块」，后续三张卡各自换内容时不再碰壳。
