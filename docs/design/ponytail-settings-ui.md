# Ponytail 设置页 · UI 规范

> **本文取代 `docs/design/ponytail-efficiency-ui.md` 中「效率区不套卡片」与「清零按钮位置」两节。**
> 其余章节（图表选型、字阶、图表颜色、空数据口径、文案纪律）仍然有效，本文只写改掉的部分与新增的定案。
> 一句话：**三张同款卡片，卡片头一个动作位，紧凑靠量根节点宽度，不靠视口。**

## 0. 硬约束

| 约束 | 检查方式 |
|---|---|
| 不出现写死的颜色 | `grep -nE '#[0-9a-fA-F]{3,8}' src/client/*.tsx` 必须零命中 |
| 颜色只走 `--dsw-alias-*` | 新增颜色引用必须是下文列出的 token 名 |
| 不出现「实时」 | `grep -rn "实时" src/ docs/` 零命中；只有「刷新」按钮与「数据截至 …」。效率卡在面板开着时每 2 秒自己重读，这是订阅期轮询，不是推送 |
| 不出现「你省了 / 实际节省」 | 效率永远只说「比没用 ponytail 的情况（基准推算）」并给出处 |
| 卡面不出现说明文字 | 每一句口径都住进 `?`，见 §8；`test/client-*-surface.test.mjs` 守着 |

## 1. 页面骨架

- 标题逐字 `Ponytail`（`<h2>`，不带版本后缀；版本号不进标题）。
- 标题下一行定位说明：`给开发者看的调试面板：…`（`<p>`，12px / 18px，`--dsw-alias-label-secondary`）。
- 三段顺序固定：**档位 → 优先级诊断链 → 效率统计**。顺序变了就是规范变了，不要各自调整。
- 三段都套同一种卡片；面板里不再有裸 `<h3>` 区块。

## 2. 卡片壳

| 属性 | 值 |
|---|---|
| 底色 | `var(--dsw-alias-bg-layer-2)` |
| 边框 | `0.5px solid var(--dsw-alias-border-l3)` |
| 圆角 | `var(--dsw-radius-md)` |
| 内边距 | `12px` |
| 卡内间距 | `gap: 12` |
| 卡头小标题 | `<h3>`，14px / 22px，600，`--dsw-alias-label-primary` |

- **卡头只有一个动作位**（右上角），空着就什么都不放：
  - 档位卡：`清除用户层覆盖`（`Button variant="outline" size="sm"`）。
  - 效率卡：数据截至 + `刷新` + `⋯`（菜单里只有「清零统计」，见 §5）。
  - 诊断卡：`打开配置文件`（见 §4.1）。
- 标题旁的 `?` 不算动作位：它挂在卡片标题（`Card.title` 收 `ReactNode`）里，与标题同行。
- 卡头 `flexWrap`：紧凑时换行，宽栏下不换行。

## 3. 档位卡

- **分段单选**：四段 off / lite / full / ultra，展示名 `off · 关闭`、`lite · 最轻`、`full · 默认`、`ultra · 最狠`。
- **每段一句悬停短说明**（性格，不复述完整对照）：
  - off：待命：不注入，需要时手写 `/ponytail` 打开
  - lite：只说更小的那个选项，不动手
  - full：默认：最小完整改动 + 一条检查 + 风险说明
  - ultra：还要质疑需求，动手前先反驳
- **`?` 悬浮四档完整对照**：一行一档，标题 `四档对照`，下面档位名 + 完整说明。文案取自
  `skills/ponytail-help/SKILL.md`。**其中 off 一条取自该文件的「关闭」节，不是「档位」表**——
  档位表里根本没有 off 那一行，照抄会得到一句空话。
- **状态行单行**：`档位｜revision N｜覆盖关系`（全角竖线分隔）。
  - 覆盖关系三种：`被环境变量覆盖` / `被配置文件覆盖` / `来自 Profile 组合层`，其余写 `无覆盖`。
  - `来自 Profile 组合层`：补丁行 `hit` 且注脚是 `DIAGNOSIS_PATCH_FROM_PROFILE`——`overriddenBy` 是 `null`
    时它分不出「谁都没写」与「组合层给了值」，得补判这一层。
  - **没有「被内置默认值覆盖」这一态**：默认值生效时它就是生效层本身，写出来只会让人以为还有一层被盖住。
  - **补丁层没写过值时也不报覆盖**（`overriddenBy` 会是 `null`），见 §4 最后一条。
  - revision 缺失写 `revision 未知`。
  - 只读时补 `｜ 配置只读`（旧版就有）。
  - 紧凑时这一行允许换行，宽栏下强制单行（`flexWrap: nowrap`）。
- 写回执：`已写入` / `未写入` 两个 Tag + 一句话，失败不抛。

## 4. 优先级诊断链卡

**三层竖排成一截管道，命中处就是答案。** 卡面上只有层名与值，没有规则句、没有图例、没有列标题。

- 三层恒画（环境变量 → 配置文件 → 内置默认值），**不筛掉没值的层**：「哪层没设」本身就是要看的信息。
- 自上而下的顺序**就是**取值顺序，不需要再说一遍「先命中的赢」。
- 一层一行，宽栏单行（层名与值基线对齐），紧凑两层（层名在上、值在下）。
- 几何：管道槽宽 32px、行高 40px；紧凑 12px / 46px。行内网格 `32px minmax(0,1fr)`，`columnGap: 10`。
- 值排版：
  - 命中：22px / 26px、600、等宽（紧凑 19px / 24px）。
  - 没赢：12px / 16px 等宽、`--dsw-alias-label-tertiary`。
  - 非法：与没赢同阶，但用 `--dsw-alias-state-danger-primary` + 600。**不加删除线**——值本身是用户写的，不该判死。
  - 不可观测：值位写 `?`。
  - 整行透明度：命中 1；没轮到（`past`）0.32；其余 1。

### 4.1 五态的画法（图形即图例）

| 状态 | 画法 |
|---|---|
| 命中 | 实心圆 r=7（紧凑 5） |
| 写了没赢 | 虚线空心圆 r=5.5；这一层保留它的值，不淡出 |
| 没轮到 | 淡出竖线 + r=2.5 小点 |
| 值非法 | 竖线在圆位断开成两截红线，中间留缺口 |
| 不可观测 | 虚线竖线 + 中间一个 `?` |

五态的中文名与 `Tag` tone **不再上卡面**，只进 `?` 的说明。

### 4.2 归因（`src/client/attribution.ts`）

- `attribute(diagnosis)` 是纯函数，出 `{ levels, effective, from }`；`levels` 恒三层。
- 归因状态是 `hit | miss | past | invalid | unknown`，**故意不沿用诊断的五态名**：诊断的 `shadowed` / `absent` 说的是「报告里的判定」，归因说的是「这一段管道怎么画」。
- 档位取值的判断走 `coerceMode()`（与 `diagnose()` 同一套归一化），大小写与首尾空白不改变归属。
- **归因的 `effective` 必须与 `diagnose()` 的生效值一致**：两处各自算一遍，测试里用七份快照做哨兵。

### 4.3 无障碍

- 容器用 `role="group"`，**不用 `role="img"`**：后者会把子树整体从无障碍树里换掉，层名与值就读不到了。
- `aria-label` 逐层叙述：`取值顺序环境变量 → 配置文件 → 内置默认值。环境变量不可观测；配置文件写 full，生效；内置默认值没轮到。当前生效 full。`
- 管道 SVG 本身 `aria-hidden="true" focusable="false"`。

### 4.4 卡头 `?`：诊断链怎么读

卡头小标题旁一个 `?`（`HelpBubble`），装下这些内容：

- 规则句的改写：`自上而下就是取值顺序，先命中的赢：环境变量 → 配置文件 → 内置默认值。`
- 三层各去哪看（`PONYTAIL_DEFAULT_MODE`、`cordis.patch.yml → ponytail-58fly.config.defaultMode`、`src/l0/mode.ts → DEFAULT_MODE`）。
- 五态画法各一句。
- **诚实说明一字不软化**：`浏览器里看不到宿主的环境变量，所以这一层永远是 ?。它没写值不代表它没生效：生效值既不等于配置值也不等于默认值时，只能是它在横。`

### 4.5 打开配置文件（票 06）

- 卡头动作位就一个按钮：`打开配置文件`（`Button variant="outline" size="sm"`），
  打开的是配置文件 `cordis.patch.yml`。
- **只打开，不复制路径**：补丁文件的绝对位置由宿主决定（`DSH_HOME` 或 profile 目录下），
  服务端也没读过它，客户端拼不出来。复制一个猜出来的路径比没有按钮更糟。
- 实现走宿主的右侧边栏服务：`sidebarRight.openResource('dsh-resource://file/session/<sessionId>/cordis.patch.yml')`。
  会话 id 从 `sidebarRight.mounted.getSnapshot()` 取，`encodeSegment` 保留冒号（Windows 盘符）。
- 三种结局都要回一句话，贴在按钮下方（11px / 17px，`--dsw-alias-label-tertiary`）：
  `已在右侧边栏打开。` / `补丁文件还没生成：先在面板里存一次档位。` / `当前没有打开的会话，右侧边栏无处可放。`
- **服务缺席就不挂按钮**：`sidebarRight` 不在组合里时，`ctx.inject` 的子 fiber 起不来，
  回调不传，面板返回 `null`。宁缺一个按钮，不留一个点了没反应的按钮。

## 5. 效率统计卡

**四块图形，自上而下。卡面上没有表头、没有指标名，只有图形与数字。**

1. **主数字 + 注入率环**：受管轮次 30px / 34px、600、等宽（紧凑 26 / 30）；右侧 `Ring`（64×64，笔画 8）。
   空态照画：主数字是 `0`，环不画进度弧——0 也是真的。
2. **四档堆叠条**：一条 10px 高的横条，按 `turnsByMode` 的**真实比例**分段，四段无缝。
   - `off` 用 `--dsw-alias-border-l3`，其余三档同一个 `--dsw-alias-state-business-primary`，
     透明度依次 0.32 / 0.62 / 1（lite / full / ultra）。
   - 轨道底色 `--dsw-alias-bg-layer-3`：`off` 段也是灰，轨道同色就等于没画。
   - 段是 flex 子项，宽度必须走 `flex: 0 0 X%`；`width` 在行内元素上不生效。
   - 四档总和为 0 时整条退化成空槽，不画零宽段。
   - 条下一行 mono 小字图例：`off 12 · lite 38 · full 71 · ultra 7`。**不写「按档位分布」这类长标签。**
3. **杂项一行**：`40.0 KB · 7 切档 · 21 命令`，mono、11px / 17px、`--dsw-alias-label-tertiary`。
4. **三行共轴区间条**：输出 / 成本 / 耗时。
   - 共用一条 `−60% … 0` 的横轴（`mini.ts` 的 `BAND_MIN` / `BAND_MAX`），轴若跟着数据缩放，三行之间就没法比长短。
   - 每行：32px 行名 + 横槽；条落在 `from`–`to` 上（4px 高、透明度 0.45），中心 2px 竖标钉住中点。
   - 轴刻度只在条下方写两端 `−60%` / `0%`，中间不画刻度线（三条共用一条轴，画线是噪音）。
   - 三项只出 `outputTokens / cost / time`；`loc`、`gzip`、`turns`、`cheaperOnTasks` 归因不到本机这些轮次。
   - 非 off 轮次为 0 时不画三行，改印一句 `还没有非 off 档位的轮次，所以没有可推算的量。`

- 卡头右端：数据截至 → `刷新` → `⋯` 菜单。
- **清零进 `⋯` 菜单**：菜单项 `清零统计`，点它只展开二次确认（`清零本机统计？` + 影响范围 + `取消` / `清零`），
  二次确认行写在卡头下方，单击绝不生效。不引 `Modal`。
- 卡底只剩一行 `上游基准，非本机测量` + 一个 `?`（`?` 里是限定语原文、推算基数、出处链接）。

## 6. 响应式

- 由**面板根节点**的 `ResizeObserver` 量自身宽度，`< 480px` 进紧凑模式。
- **不用 CSS 媒体查询**：设置页嵌在侧栏、分屏里，视口宽度 ≠ 面板宽度，媒体查询量错了对象。
- 量不到 `ResizeObserver`（老浏览器、测试桩）时降级成宽栏，不挂。
- 回调走 `requestAnimationFrame` 合并，避免同步 setState 触发 `ResizeObserver loop` 警告。
- `compact` 由面板量一次后作为 prop 往下传，卡片自己不测宽。
- 紧凑下的具体让步：管道槽 32→12px、行高 40→46px，层名与值改上下两行；命中值 22→19px；
  主数字 30→26px；卡头动作位换行。**宽度降到 320px 时仍然不横向滚动**（四块图形本身是纵向排布）。

- `/ponytail-gain` 末行与卡片标题逐字一致：`面板里有图形版：设置 → Ponytail → 效率统计。`

## 8. 诚实纪律

- 不写死色值，只用 `--dsw-alias-*` 与官方 primitives。
- 不出现「实时」：只有「刷新」按钮与「数据截至 HH:MM」。轮询只改数字，不改这句口径。
- 不出现「你省了 / 实际节省」：效率一律给区间 + 出处 + 限定语，`?` 里也这么说。
- 空态、读不到、可观测性缺失各有各的完整句子，不用感叹号和警告三角。

### 8.1 说明文字只住 `?`

卡面上不允许出现解释性句子。每一句原话的归属：

| `?` 入口 | 装什么 |
|---|---|
| 档位卡头 | 四档完整对照（`MODE_HELP`） |
| 诊断卡头 | 规则句、三层出处、五态画法、环境变量那条诚实说明 |
| 主数字后 | 什么算一轮 |
| 注入率环后 | 注入率怎么算、环空着代表什么 |
| 杂项行末 | 注入字节 / 切档 / 命令三个口径 |
| 堆叠条图例后 | `off` 灰段是什么、它不进推算基数 |
| 卡底基准行后 | 限定语原文、推算基数、上游出处链接 |

- 全部走宿主 `HoverCard`，不新增工具提示组件、不引入依赖。
- 两个卡面守卫（`test/client-panel-surface.test.mjs`、`test/client-efficiency-surface.test.mjs`）用
  `test/surface.mjs` 的 `withoutHelp()` 削掉 `?` 正文后再扫，正面清单另外断言这些句子**在 `?` 里还在**。
