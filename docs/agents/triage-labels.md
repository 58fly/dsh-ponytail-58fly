# 分诊标签词汇

技能内部的叙述使用五个固定的分诊角色。本文件把这五个角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| 技能里的标签 | 本仓库使用的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 需要维护者评估这张票 |
| `needs-info`               | `needs-info`         | 在等报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 描述完整，可交给无人值守的 agent 处理 |
| `ready-for-human`          | `ready-for-human`    | 必须由人来实现 |
| `wontfix`                  | `wontfix`            | 不做处理 |

当某个技能提到某个角色（例如「打上 AFK-ready 分诊标签」）时，使用表格里对应的标签字符串。

本仓库保留默认五角色，标签字符串与角色名一一相同，无需做任何覆盖映射。若将来 tracker 里已在用别的名字（例如用 `bug:triage` 表示 `needs-triage`），只改「本仓库使用的标签」这一列即可，避免技能重复创建标签。
